# WTG — приложение «куда пойти» (интерактивный прототип)

Веб-версия интерфейса мобильного приложения WTG: карта Ростова-на-Дону, места и события, афиша, подборки, профиль. Демонстрация интерфейса, а не рабочий сервис.

**Демо:** https://awon-lmv.github.io/wtg-app/

- Данные каталога (8 мест, 6 событий) — ручной снимок 21.10.2026, не live. Фото и афиши подгружаются с сайтов заведений и операторов билетов, они принадлежат их владельцам.
- Сохранения, оценки и подборки живут только в памяти текущего сеанса; сервера нет.
- Подложка карты — OpenFreeMap (без ключа). Если задать `VITE_MAPBOX_TOKEN` (см. `.env.example`), подключится Mapbox; токен нужно ограничить по адресу сайта.

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/ (для GitHub Pages base = /wtg-app/)
```
